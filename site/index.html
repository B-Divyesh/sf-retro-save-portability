How it works

Scan, bundle, then restore.

  1. 01 / Scan

    Choose a save folder.

    The app reads supported saves inside your selected folder. It does not change the source.

  2. 02 / Bundle

    Create a portable bundle.

    The bundle records each save’s path, format, size, timestamp, emulator evidence, and SHA-256 hash.

  3. 03 / Restore

    Review the restore.

    The app shows compatibility and replacement warnings. It checks each save before writing it.

Supported save files

Check detected formats and limits.

Detection uses file extensions and folder names. Uncertain results are marked for review.

Recognised folders

RetroArch, DuckStation, PCSX2, Dolphin, mGBA, VisualBoyAdvance, DeSmuME, melonDS, Snes9x, PPSSPP, and BizHawk.

Recognised formats

SRM, SAV, RTC, MCR, MC, RAW, DSV, SPS, GCI, EEP, FLA, RAM, NV, FS, and DAT saves.

Compatibility limits

Save states are excluded. Region, game revision, core, firmware, and memory-card differences can make a save incompatible.

Common questions

Limits and data handling.

Does it include emulators, games, or BIOS files?

No. It recognises save files in folders you select. It does not distribute or copy ROM or BIOS files.

Will every save work in every emulator?

No. Formats, regions, revisions, cores, and memory-card layouts differ. Keep the source until the destination game loads.

Where does my data go?

Save processing stays on your device. License verification contacts Sociobot only after you add a Keeper license.
