Practical coverage

Know the label. Respect the exception.

Detection uses extension and folder evidence, never a guess disguised as certainty.

Recognised paths

RetroArch, DuckStation, PCSX2, Dolphin, mGBA, VisualBoyAdvance, DeSmuME, melonDS, Snes9x, PPSSPP, and BizHawk.

Recognised formats

SRM, SAV, RTC, MCR, MC, RAW, DSV, SPS, GCI, EEP, FLA, RAM, NV, FS, and emulator DAT saves.

Honest limits

Save states are emulator-specific and intentionally excluded. Region, game revision, core, and firmware differences can still make a valid save incompatible.

Before you ask

Built to be cautious.

Does it include emulators, games, or BIOS files?

No. It recognises save files in folders you select. It neither distributes nor copies ROM or BIOS files.

Will every save work in every emulator?

No utility can promise that. Save formats, regions, game revisions, cores, and memory-card layouts differ. The app records evidence and warns about known mismatches; always keep the source until you verify the game loads.

Where does my data go?

Your folders, save contents, manifests, and journal stay on your device. Only license verification contacts Sociobot when Keeper is activated.
