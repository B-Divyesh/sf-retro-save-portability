Emulator notes

Check emulator save differences.

A valid save may not work in every emulator. Keep the source until the destination game loads.

RetroArch

RetroArch hardware saves commonly use .srm. Save states are different and are excluded.

Core changes can alter file size or naming. Close RetroArch before restoring so it cannot overwrite the file on exit.

mGBA and VisualBoyAdvance

.sav battery saves are often portable. Some games use different flash or EEPROM types and sizes.

Use the emulator’s native export command when it provides one.

DuckStation and PCSX2

Memory-card files may contain one game or several games. Replacing one file can replace the whole card.

The restore check names existing destinations. Review each replacement.

Dolphin

GameCube .gci files contain individual saves. Raw memory-card images can contain several saves.

Version 0.1.3 does not move Wii NAND saves. Use Dolphin’s import and export tools for NAND content.

DeSmuME and melonDS

DeSmuME .dsv and general .sav files can differ in footer data and expected size.

Use the emulator’s conversion or export option when moving between emulator families.

PPSSPP and folder saves

Some systems store one save across several files. Version 0.1.3 inventories recognised files, not arbitrary folder packages.

Use the emulator’s documented whole-folder copy process for these saves.

Results marked “review”

The file extension is recognised, but its folder did not identify an emulator.

Compare the emulators, game region, revision, filename, and expected size before restoring.
